# Personal Valentine letter

Personalized fork of [lovesulei/valentine-ask](https://github.com/lovesulei/valentine-ask). The original design, illustration assets, and implementation originate upstream; this is a personal adaptation rather than an independently original engineering project. No license rights to upstream assets are invented here.

Open `index.html` or run `python3 -m http.server 8000`. Personalize the recipient text and date in `index.html`. The envelope and both answers are native buttons, reachable by keyboard or touch. Both choices stay in place, focus moves to the opened letter, and reduced-motion preferences are respected.
